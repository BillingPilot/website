# BillingPilot-Website

Dieser Ordner enthält den eigenständigen Entwurf der öffentlichen, statischen BillingPilot-Website.

## Lokal ansehen

`index.html` direkt im Browser öffnen. Es werden keine Abhängigkeiten, Server oder Build-Schritte benötigt.

## Vor der Veröffentlichung ersetzen

- `kontakt@billingpilot.de` durch die tatsächliche Kontaktadresse ersetzen.
- `datenschutz.html` und `impressum.html` mit rechtsgeprüften Inhalten anlegen.
- Den deaktivierten Download erst nach Bereitstellung eines geprüften, signierten Release-Installers aktivieren.
- Versionsnummer, SHA-256-Prüfsumme und Release Notes des Releases ergänzen.
